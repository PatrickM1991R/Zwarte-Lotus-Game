# De Zwarte Lotus v8.8 — fase 4 onderzoeksopdracht

Deze versie is gebaseerd op v8.7 en vervangt alleen fase 4.

- De naam van de informant verschijnt niet in de nieuwe briefing.
- De opdracht luidt **Zoek de juiste infiltrant.**
- De twee antwoordvelden zijn verwijderd.
- Er is een knop om naar het containerregister te gaan. Deze actie veroorzaakt geen tijdstraf.
- De bestaande timer, hints en overige puzzels zijn ongewijzigd.

## GitHub
Pak de volledige ZIP uit en upload de inhoud in de root van je repository (niet de buitenste map). Laat bestanden met dezelfde naam overschrijven.

De hotfix bevat `client/src/main.jsx`, `client/src/styles.css` en `server/src/index.js`. Omdat de servercontrole verandert, moeten frontend en backend opnieuw worden gedeployed.
