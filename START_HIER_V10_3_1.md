# De Zwarte Lotus v10.3.1

Als een team al in een fase van Johnny zit en de route ontbreekt, herstelt de server de route bij het ophalen van de spelstatus. De bestaande spelfase, speeltijd en strafminuten blijven behouden. Het dashboard wijst de route ook meteen toe wanneer de spelbegeleider een team vanaf de keuzefase naar Johnny doorschuift.

Werk de bestanden in GitHub bij en laat Render de client en server opnieuw deployen. Laat een vastgelopen team daarna het spel verversen.
